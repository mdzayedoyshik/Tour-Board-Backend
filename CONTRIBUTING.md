# Contributing

Thanks for taking the time to help.

## Reporting a bug or asking for a feature

Open an issue with what you expected, what happened, and the steps to reproduce it. Screenshots or logs help a lot.

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep each pull request focused on one change.
3. Run the checks before you push:

   ```bash
   npm install
   npm test
   ```

4. Describe what changed and why in the pull request.

## Security

Please do not open a public issue for security problems. Email zayedoyshik1@gmail.com instead.

## Secrets

Never commit `.env` files, service account keys or API keys. Copy the example env file and keep your values local.
